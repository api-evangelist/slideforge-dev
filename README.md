SlideForge is a controllable rendering engine for PowerPoint presentations, offering an API and Model Context Protocol (MCP) that lets AI agents and developers generate board‑grade PPTX files from structured intents or code. The service provides over 200 slide‑template layouts, integrates with Claude, Cursor, and other AI models, and includes pricing, documentation, templates, and a web console for testing. Operated by Smart Data Brokers GmbH in Zurich, Switzerland, SlideForge targets developers building AI‑driven slide generation workflows.

**Areas:** Company · AI · Presentation · API · MCP
